# Walmart Retail sales Project
## Project Overview
In This project, I analyze walmart retails sales business insights using SQL Subqueries,The goal is to extract valuable insights and answer various business questions based on the dataset. The following README provides a detailed account of the project's Purpose, business problems, findings, and conclusions.
## Dataset
The data for this project is sourced from the Kaggle dataset.
